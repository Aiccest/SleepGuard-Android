# SleepMate

**让用户安心入睡，让手机及时休息。**

SleepMate 是一款面向 Android 的开源睡眠保护与省电应用。用户看视频、听媒体内容时不小心睡着，SleepMate 会在满足完整睡眠判定条件后暂停媒体播放并锁定屏幕，减少不必要的耗电。

SleepMate 的目标是在尽量低功耗的前提下，判断用户是否已经入睡；在确认后暂停媒体播放并锁定屏幕，减少无意义的亮屏和播放耗电。

> **项目状态：开发原型，尚未达到可公开发布的稳定版本。** 当前自动睡眠检测链路尚未通过完整构建和真机验证。仓库中的实现、界面说明和设计目标不代表所有功能已经可靠可用。

## 核心目标

- 仅监测用户明确勾选的媒体应用；未勾选的应用不触发检测，也不执行媒体暂停。
- 用户可在应用内按已安装应用列表逐个勾选或取消，选择保存在本机；默认不选择任何应用。
- 优先使用低功耗信号判断设备是否长时间没有活动。
- 满足空闲和静止条件后，才短暂调用前置摄像头进行辅助判断。
- 在设备本地分析画面；目标是不上传摄像头画面或人脸数据。
- 达到睡眠判定条件后，暂停可控制的媒体会话，并在具备设备管理员授权时锁定屏幕。
- 检测结束、媒体停止或设备活动时，及时释放摄像头和传感器资源。

## 设计中的检测节奏

以下是当前设计目标，不是已经通过真机验证的性能承诺：

1. 只有用户勾选的应用开始播放媒体后，才进入低功耗等待；默认空选择时不监测任何第三方应用。
2. 约 5 分钟没有明显设备活动后，进入检测准备。
3. 手机保持静止约 8 秒后，在系统允许时启动短时摄像头检测。
4. 单次检测最长约 30 秒；持续闭眼约 3 秒作为辅助判断条件。
5. 未确认睡眠时，计划按 15、20、25 分钟递增复查，之后最多每 30 分钟复查。
6. 检测到设备活动或媒体停止时，取消当前候选并重新计时。

## Android 平台限制

SleepMate 不应承诺 Android 系统无法保证的行为：

- 普通 Android 应用无法可靠读取其他应用内的全部触摸事件；设备运动只能作为活动代理信号，不能等同于真实触摸。
- Android 对后台摄像头访问有严格限制。屏幕关闭或应用处于后台时，系统可能不允许启动摄像头；检测必须遵循系统权限和前台服务规则。
- 媒体会话是否可见、是否允许暂停，取决于媒体应用及其会话实现。
- 小米等厂商系统可能额外限制后台运行、自启动和电池使用。
- 因此，自动暂停、睡眠识别、后台检测和省电效果都必须在目标设备上逐项验证。

## 隐私与权限

SleepMate 的设计原则是尽可能在设备本地完成检测，不收集、不上传摄像头画面或人脸信息。请查看 [隐私说明](PRIVACY.md)。

应用可能需要以下系统授权：

| 权限 / 授权 | 用途 |
|---|---|
| 摄像头 | 在满足条件时进行短时辅助睡眠检测 |
| 通知使用权（媒体通知访问） | 读取活动媒体会话状态，并尝试控制可用的媒体会话 |
| 设备管理员 | 在用户明确激活后锁定屏幕 |
| 通知权限 | 显示前台保护服务状态 |
| 前台服务 | 按 Android 系统要求运行用户可见的保护任务 |

任何权限都应向用户解释用途；用户不授权时，对应功能应明确提示不可用，不应伪装成已启用。
