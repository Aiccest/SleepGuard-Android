# SleepMate

**让用户安心入睡，让手机及时休息。**

SleepMate 是一款面向 Android 的开源睡眠保护与省电应用。用户在自己选择的应用中使用手机时，SleepMate 根据设备活动和短时前置摄像头检测判断是否可能入睡；满足睡眠判定条件后尝试锁定屏幕，减少不必要的亮屏耗电。

> **项目状态：开发原型，尚未达到可公开发布的稳定版本。** 当前自动睡眠检测链路尚未完成全面构建与真机验证。仓库中的实现、界面说明和设计目标不代表所有功能已经可靠可用。

## 核心目标

- 仅监测用户明确勾选的应用；任一所选应用处于前台时进行监测，离开全部所选应用后暂停。
- 用户可在应用内按已安装应用列表逐个勾选或取消，选择保存在本机；默认不选择任何应用。
- 在已选应用之间切换时，监测保持连续，不因切换而重新开始无活动计时。
- 使用加速度传感器判断设备活动和静止状态；进入所选应用前台后启动活动传感器。
- 满足无明显活动和手机静止条件后，才尝试短暂调用前置摄像头进行辅助判断。
- 在设备本地分析画面；目标是不上传摄像头画面或人脸数据。
- 达到睡眠判定条件后，已授权设备管理员时直接锁定屏幕；未授权时尝试返回桌面。

## 当前睡眠检测流程

以下描述当前代码中的设计逻辑，不是已经通过所有设备真机验证的性能承诺：

1. 用户选择的应用进入前台后，注册加速度传感器并开始活动监测；离开全部所选应用后暂停监测。
2. 设备约 5 分钟没有明显活动后，继续等待手机保持静止约 8 秒。
3. 条件满足且 Android 系统允许时，启动前置摄像头，进行最长约 30 秒的检测窗口。
4. 睡眠判断有三条路径：
   - **路径 A：双眼闭合。** 成功识别到左右眼，且双眼睁眼概率均低于 0.25，持续约 3 秒；同时手机满足静止条件。
   - **路径 B：窗口内无人脸。** 整个 30 秒检测窗口都没有检测到人脸；同时摄像头取得有效检测画面，手机满足静止条件。
   - **路径 C：检测到人脸但无法识别双眼。** 窗口内至少检测到过一次人脸，但整个 30 秒窗口始终没有成功获得左右眼概率；同时摄像头取得有效检测画面，手机满足静止条件。只要本轮任何一帧成功获得左右眼概率，路径 C 就不成立。
5. 摄像头无法启动、检测异常或没有有效画面时，不按睡眠处理。
6. 未确认睡眠时，后续复查间隔按 15、20、25、30 分钟安排，之后每 30 分钟复查。
7. 用户离开全部所选应用、屏幕熄灭或设备明显移动时，停止或暂停相应检测；设备移动会重置无活动计时。

## 人脸二次验证实验（实验分支）

本分支在原有 ML Kit 候选人脸检测之后，加入 MediaPipe Face Landmarker 进行同帧面部关键点验证。ML Kit 候选框不会单独被视为可靠人脸；还需检查面部网格与候选框重叠，以及双眼、鼻尖、上下唇的相对位置和几何关系。验证通过后才允许原有 A/B/C 逻辑使用该人脸及 ML Kit 双眼概率。

- 人脸宽度低于输入画面宽度的 5% 时拒绝采纳。
- 5% 至 8% 区间执行更严格的眼间距和五官相对位置检查；8% 以上执行常规结构检查。
- 这些百分比是当前实验阈值，尚未通过不同手机、距离、角度和侧脸场景校准，不代表通用识别保证。
- MediaPipe 使用随 APK 打包的 `face_landmarker.task`，运行时从本地 assets 加载。模型构建时下载并校验 SHA-256；App 不需要为模型下载增加网络权限。
- 摄像头帧、面部关键点及检测结果仅在设备内存中处理；本实现不上传图像或人脸数据。
- MediaPipe 验证初始化或处理失败时，本轮不满足 B/C 的有效分析条件，避免将模型故障误判成无人脸。

## Android 平台限制

SleepMate 不应承诺 Android 系统无法保证的行为：

- 普通 Android 应用无法可靠读取其他应用内的全部触摸事件；设备运动只能作为活动代理信号，不能等同于真实触摸。
- 前台应用识别依赖 Android 使用情况访问权限；系统多窗口和厂商后台策略可能影响识别，部分系统也可能延迟更新应用切换状态。
- Android 对后台摄像头访问有严格限制。屏幕关闭或应用处于后台时，系统可能不允许启动摄像头；检测必须遵循系统权限和前台服务规则。Android 版本及厂商系统会影响实际行为。
- 小米等厂商系统可能额外限制后台运行、自启动和电池使用。
- 因此，睡眠识别、后台检测和省电效果都必须在目标设备上逐项验证。

## 隐私与权限

SleepMate 的设计原则是尽可能在设备本地完成检测，不收集、不上传摄像头画面或人脸信息。请查看 [隐私说明](PRIVACY.md)。

应用可能需要以下系统授权：

| 权限 / 授权 | 用途 |
|---|---|
| 摄像头 | 在满足条件时进行短时辅助睡眠检测 |
| 使用情况访问 | 识别当前前台应用是否属于用户选择的应用 |
| 设备管理员 | 在用户明确激活后锁定屏幕 |
| 通知权限 | 显示前台保护服务状态 |
| 前台服务 | 按 Android 系统要求运行用户可见的保护任务 |

任何权限都应向用户解释用途；用户不授权时，对应功能应明确提示不可用，不应伪装成已启用。
